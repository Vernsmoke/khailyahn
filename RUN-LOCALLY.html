Run Gym Management on this PC

Use this guide to test the separate Hostinger edition on any Windows computer before uploading it. The folder can be extracted anywhere; the commands do not depend on a Windows username or Downloads location.

Safe test setup: use a new database named gym_hostinger_local. Do not use your current gym database or a Hostinger production database.

0. Download, extract, and install the local software

  1. Download DOWNLOAD-Gym-Management-Hostinger.zip onto the other computer.
  2. Right-click it, choose Extract All, and open the extracted Gym Management Hostinger folder. Do not run the project while it is still inside the ZIP.
  3. Install the Windows PHP 8.2 version of XAMPP from the official Apache Friends download page. The normal install location is C:\xampp.

If XAMPP is installed somewhere else, replace C:\xampp in the commands below with that location.

Enable and check the required PHP extensions

The app needs PDO MySQL, mbstring, GD, and fileinfo. In some XAMPP installations GD starts disabled:

  1. Close any running local PHP server.
  2. Open C:\xampp\php\php.ini in a text editor. If Windows refuses to save it, open the editor as Administrator.
  3. Find ;extension=gd. If it begins with a semicolon, remove the semicolon so it reads extension=gd.
  4. Save the file and restart Apache if it was running.
  5. In PowerShell, run this check:
C:\xampp\php\php.exe -r 'foreach (["pdo_mysql","mbstring","gd","fileinfo"] as $e) echo $e, ": ", extension_loaded($e) ? "enabled" : "DISABLED", PHP_EOL;'

All four lines should say enabled.

1. Start MySQL

  1. Open XAMPP Control Panel.
  2. Click Start beside MySQL.
  3. For the easiest database import, also start Apache, then open http://localhost/phpmyadmin/.

If MySQL will not start, another MySQL service may already be using port 3306. Do not delete any MySQL data folders. Check the XAMPP log first.

2. Create an empty local database

  1. In phpMyAdmin, select Databases.
  2. Enter gym_hostinger_local.
  3. Select collation utf8mb4_unicode_ci, then click Create.
  4. Select the new database and choose Import.
  5. Click Choose File. Open the extracted project folder, then select database\schema.sql.
  6. Click Import or Go. Tables including member, payment, and user_account should appear.

Import this file only into a new empty test database. It is an initial schema, not an update script.

3. Create the local private configuration

  1. In File Explorer, open the extracted Gym Management Hostinger folder. Click the address bar, type powershell, and press Enter. This opens PowerShell in the correct folder regardless of where you extracted it.
  2. Run these commands:
Copy-Item "server\config.example.php" "server\config.php"
C:\xampp\php\php.exe -r "echo bin2hex(random_bytes(24)), PHP_EOL;"

Copy the random value printed by the last command. Open server\config.php in Notepad and use these local values:

<?php
return [
 'db_host' => 'localhost',
 'db_port' => 3306,
 'db_name' => 'gym_hostinger_local',
 'db_user' => 'root',
 'db_password' => '',
 'app_origin' => 'http://127.0.0.1:8097',
 'cookie_secure' => false,
 'setup_token' => 'PASTE_THE_RANDOM_VALUE_HERE',
];

XAMPP normally uses local user root with an empty password. If you previously added a MySQL password, enter it in db_password.

4. Start the website

Double-click START-LOCAL-SERVER.cmd. You can also run this command from PowerShell opened in the extracted project folder:

C:\xampp\php\php.exe -S 127.0.0.1:8097 -t public_html tests/router.php

Keep that PowerShell window open. A line containing Development Server started means the local website is running.

5. Create your first test administrator

  1. Open http://127.0.0.1:8097/setup.html.
  2. Enter the random setup token from step 3.
  3. Create a test administrator name, username, and password. The password must contain 12–128 characters.
  4. After setup succeeds, sign in at http://127.0.0.1:8097/login.

The setup endpoint becomes unavailable after the first account is created. This is expected.

6. Test the important workflows

  • Register a sample member and upload a small photo.
  • Confirm annual-only membership is denied at entry until a monthly payment exists.
  • Record a monthly payment and confirm QR entry becomes approved.
  • Create a Staff account and confirm it cannot open administrator-only pages.
  • Refresh direct pages such as /members.
  • Test the scanner with manual QR text first. Camera access on localhost depends on browser permissions and available hardware.

7. Stop and restart later

Press Ctrl + C in the PowerShell server window to stop the website. Stop MySQL and Apache from XAMPP when you no longer need them.

To run it again later, start MySQL and double-click START-LOCAL-SERVER.cmd. Your test data remains in gym_hostinger_local.

Troubleshooting

ProblemWhat to check
Database connection errorMySQL is running; database name, user, password, and port in server\config.php are correct.
Origin verification failedOpen exactly http://127.0.0.1:8097. Do not substitute localhost unless you also change app_origin.
Port 8097 already in useUse another port in both the server command and app_origin, for example 8099.
Setup token rejectedCopy it exactly and confirm it is saved inside server\config.php. Setup works only before the first account exists.
Blank/error pageRead the message in the PowerShell server window. Confirm PHP extensions pdo_mysql, mbstring, gd, and fileinfo are enabled.
XAMPP is not foundInstall it in C:\xampp, or edit PHP_EXE near the top of START-LOCAL-SERVER.cmd to use your PHP location.

Before uploading to Hostinger

Local server\config.php is for that PC only and is excluded from every supplied ZIP. Hostinger needs a new production database and a new private config.php using the Hostinger credentials, HTTPS domain, and cookie_secure => true. Follow START-HERE.html for deployment.
